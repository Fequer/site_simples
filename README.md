# Simple website

Fundamental information for working in web development, learning to use HTML, CSS, and JavaScript to create websites.

An introduction to the basic components of a website and the tools you can use to begin web development.

A simple proof-of-concept website demonstrating theme support via CSS, including a JavaScript function to toggle between themes.

An exercise from the course "Crie um site simples usando HTML, CSS e JavaScript" offered by Fundação Bradesco - Escola Virtual.
